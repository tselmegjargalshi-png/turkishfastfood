# İstanbul Fast Food · Цахим цэс

Монгол хэлтэй (TR сонголттой) цахим цэс ба удирдлагын самбар. Хоолны нэр Турк хэлээр, үнэ Турк лираар (₺).

**Шууд холбоос:** https://turkishfastfood.vercel.app  
**Удирдлага:** https://turkishfastfood.vercel.app/admin

## Юу багтсан бэ

| Хэсэг | Тайлбар |
| --- | --- |
| Цэс (`/`) | 7 ангилал, 39 хоол. Ангиллын наалддаг цэс, хайлт, 14 харшлын шүүлтүүр, цагаан хоол / халуун ногоогүй шүүлтүүр, хоол бүрийн дэлгэрэнгүй цонх, нээлттэй эсэх төлөв (Истанбулын цагаар), Тогоочийн онцлох, сурталчилгааны баннер. |
| Удирдлага (`/admin`) | Нууц үгээр нэвтэрнэ. Ангилал, хоол, үнэ, kcal, харшил, тэмдэглэгээ засах, дараалал солих, зураг оруулах (лого солих, баннер болгох), холбоо барих мэдээлэл, JSON нөөц татах/оруулах, QR татах. |
| QR (`/qr`) | `qr_table_card.png` ширээний карт, `qr_sticker.png` дугуй наалт. Хоёулаа шалгагдсан (уншигдана). |

## Хадгалалт хэрхэн ажилладаг вэ

* Анхны цэс `data/menu.json` дотор байна.
* Админаас **Хадгалах** дарахад цэс Vercel Blob (`data/menu.json`) руу бичигдэнэ. Нүүр хуудас `/api/menu`-гээс уншина; Blob хоосон эсвэл холбогдоогүй бол `data/menu.json`-г ашиглана.
* Хадгалсан өөрчлөлт 1 минутын дотор цэсэнд харагдана. Хадгалах бүрт `data/backups/` дотор нөөц хуулбар үүснэ.
* Зураг `media/` хавтсанд Blob дээр хадгалагдана (4MB хүртэл, том зургийг хөтөч дээр 1600px болгож шахна).

## Vercel тохиргоо

Project Settings → Environment Variables:

| Нэр | Утга |
| --- | --- |
| `ADMIN_PASSWORD` | Админы нууц үг (заавал) |
| `BLOB_READ_WRITE_TOKEN` | Storage → Blob store холбоход автоматаар үүснэ |

Нууц үг солих: Vercel → turkishfastfood → Settings → Environment Variables → `ADMIN_PASSWORD` засаад **Redeploy** хийнэ.

## Локал ажиллуулах

```bash
npm install
ADMIN_PASSWORD=test node scripts/dev.mjs   # http://localhost:3000
```

## QR дахин үүсгэх (домэйн солигдвол)

```bash
npm i -D qrcode jsqr pngjs playwright && npx playwright install chromium
node scripts/make-qr.cjs https://шинэ-домэйн
```
